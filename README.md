# Deep Scanner — Legal

Public legal documents for the **Deep Scanner** iOS app.

- [Privacy Policy](privacy.md)
- [Terms of Use](terms.md)

Once GitHub Pages is enabled for this repository, these documents will be
available at:

- `https://<your-username>.github.io/aegis-legal/privacy`
- `https://<your-username>.github.io/aegis-legal/terms`

Use those URLs in App Store Connect (Privacy Policy URL, EULA URL) and inside
the app's Settings screen.

## Updating

1. Edit `privacy.md` or `terms.md`.
2. Bump the **Last updated** date at the top of the changed file.
3. Commit and push — GitHub Pages will rebuild automatically.
